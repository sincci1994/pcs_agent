J-매트릭스 상세 — 판단 케이스 9종 (D1~D5 × B1~B5)

ID조건 조합상태 분류해석 · 원인 후보점검 대상 구간 (B1)
J-01

Gas 사용률이 추정 임계값 가까이 누적됐지만, 압력은 아직 정상 범위를 유지하는 경우

D1 높음 + D2 정상		관찰 필요교체주기 임박, 예방관리 후보(점검 아닌 관찰) 교체·클리닝 일정 검토
J-02

사용률이 높은 상태에서 압력도 상압 대비 높거나 상승 추세이고, 히팅센서는 정상인 경우 — 사용량으로 설명되는 전형적인 파우더 누적 신호

D1 높음 + D2 높음·상승 + D3 정상		점검 후보파우더 누적 가능성SD1, MERGE 합류부, NOR밸브 (측정점 확정 시 B2로 좁힘)
J-03

사용률이 낮아 누적으로는 설명되지 않는데 압력이 높고, 히팅센서 온도가 정상범위 아래로 이탈해 있는 경우 — 가스가 식은 구간의 국부 파우더 생성 의심

D1 낮음 + D2 높음 + D3 이탈		원인 확인 필요히팅 이탈 구간의 국부 파우더 생성 또는 Heating Jacket 자체 이상D3 이탈 센서가 위치한 구간 우선
J-04

클리닝·교체 작업 직후라 누적이 리셋됐고 히팅센서도 정상인데, 압력만 높게 유지되는 경우 — 실제 막힘보다 지시값 왜곡 가능성부터 확인

D1 낮음 + D2 높음 + D3 정상 + D4 작업 직후		원인 확인 필요Sensor Port 막힘, 작업 범위 누락, 센서 이상Sensor Port → 직전 작업 범위 순
J-05

작업으로 내려갔던 압력이 기준 기간(P-05) 안에 작업 전 수준 가까이 다시 오르는 경우

D4 작업 후 D2 재상승 (P-05)		원인 확인 필요작업 범위 누락, 센서·보조장치 문제, 급격한 파우더 재생성직전 작업에서 제외된 구간부터
J-06

누적 사용률은 중간 수준인데 압력이 상승 중이고, 순간(peak) 사용량이 큰 레시피를 쓰는 Chamber가 물려 있는 경우 — 총량보다 빠른 조기 파우더화 의심

D1 중간 + D2 상승 + D5 peak 상위 레시피		점검 후보순간 사용량에 의한 조기 파우더화 가능성기여 상위 Chamber의 FORELINE (B5 역추적)
J-07

Pair 상대 설비가 점검에 들어가 바이패스로 가동 중이라, 상대 몫의 가스까지 내 스크러버로 흘러 부하가 커져 있는 기간

Pair 상대 점검·BYP 가동 중		관찰 필요 (자동 승격)바이패스로 부하 전가 중자기 스크러버군 전체 (부하 증가 기간)
J-08

바이패스 전환 이력이 있는데 상대 스크러버의 사용률이 급증한 경우 — 사용량이 엉뚱한 설비에 귀속됐을 수 있어 판단보다 보정이 먼저

BYP 전환 이력 + 상대 스크러버 D1 급증		보정 후 재판단사용량 귀속 오류 가능성 — 판단 전에 B3 귀속 보정 필요—
J-09

위 케이스(J-02~J-05) 중 2개 이상이 한 계통에서 동시에 성립하거나, 같은 스크러버군에서 기준 기간(P-08) 내 반복해서 발생하는 경우

J-02~J-05 중 2개 이상 동시 또는 반복 이슈 (P-08)		우선 점검 후보복합 요인해당 케이스들의 구간 합집합, 순서는 스코어 순

※ J-08은 상태가 아니라 판단 전 보정 단계다 — 보정 없이 D1을 쓰면 J-01·J-02 오탐이 난다. 어떤 케이스에도 해당하지 않으면 "정상"으로 분류하되 D1·D2 수치는 항상 함께 보고한다. 조건의 높음·낮음 경계는 전부 가정값(P-01~P-08)이며 현업 워크숍으로 확정한다.

가드레일 — Agent는 상태를 분류하고 근거를 제시할 뿐, 위험을 단정하거나 작업을 지시하지 않는다. 작업요청 자동 발행은 명확한 운영 기준 충족 시에만 수행하고, 모든 경계값은 가정값으로 시작해 현업 워크숍(Q1~Q8)으로만 확정한다. 최종 판단은 엔지니어가 수행한다.
